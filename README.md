# PRODIGY_ML_01 - Task 1

Run `python setup_project.py` to create any missing folders and starter files without overwriting existing files. Use `--target-dir PATH` to choose another project directory.

Place `train.csv` and `test.csv` in `dataset/`, install dependencies with `python -m pip install -r requirements.txt`, then run `python src/train_model.py` to evaluate the model and create `dataset/submission.csv`.
